📚 Frequently Asked Questions

How do I install the add-in?
1. Open Outlook on the web (outlook.office.com)
2. Click Settings (⚙️) → View all Outlook settings
3. Go to General → Manage add-ins
4. Click "+ Add a custom add-in" → "Add from URL"
5. Enter: https://task-manager.digitaldream.work/outlook/manifest.json
6. Click Install
The add-in doesn't appear in Outlook
Try these steps:
• Refresh your browser (or restart Outlook Desktop)
• Clear your browser cache
• Verify the add-in is installed in Settings → Manage Add-ins
• Try using the JSON manifest instead of XML
• Check if you're using a supported Outlook version
I get "CORS error" when creating tasks
This usually means:
• The server is not configured to accept requests from Outlook domains
• Your network/firewall is blocking the connection
• Try accessing the main app at task-manager.digitaldream.work first
• Contact your IT administrator if you're in a corporate environment
Users don't appear in the dropdown
Make sure:
• You have users created in the main Task Manager app
• You're connected to the internet
• The API endpoint is accessible (check browser console F12)
• CORS is properly configured on the server
Can I use this on Outlook mobile?
The JSON manifest supports Outlook mobile, but the experience may be limited. We recommend using Outlook Web or Desktop for the best experience.
Is my email data stored on your servers?
No. We only store the task information you explicitly create. We do not access, read, or store your email content beyond what you choose to include in task notes. See our Privacy Policy for details.
How do I uninstall the add-in?
1. Open Outlook settings
2. Go to General → Manage add-ins
3. Find "Task Manager" in the list
4. Click the trash/delete icon
5. Confirm removal
What permissions does the add-in need?
The add-in requires MailboxItem.Read.User permission to:
• Read the subject of the current email
• Read the sender information
• Read the email body (only when you create a task)

We do NOT access any other emails or your contacts.

🔧 Troubleshooting Steps

1. Check Add-in Status

  • Open Outlook settings → Manage add-ins
  • Verify "Task Manager" is listed and enabled
  • Check if there are any error messages

2. Clear Cache

  • Outlook Web: Clear browser cache (Ctrl+Shift+Delete)
  • Outlook Desktop: Close and restart Outlook
  • Re-login to Outlook

3. Check Browser Console

  • When the add-in is open, press F12
  • Go to the Console tab
  • Look for error messages (red text)
  • Send us the error message for faster support

4. Verify Connectivity

  • Open https://task-manager.digitaldream.work in your browser
  • Verify you can access the main app
  • Try creating a task in the main app
